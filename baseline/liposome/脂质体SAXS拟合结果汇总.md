# 脂质体 SAXS 拟合分析：参数与结论汇总

**日期**: 2026-09-18

**数据**:

| 样品 | 数据文件 | 数据点 | q 范围 (nm⁻¹) |
|---|---|---|---|
| 不含PEG脂质体 | `测试数据/R0-26080301-不含PEG脂质体.dat` | 798 | 0.30 – 4.36 |
| 含PEG脂质体 | `测试数据/20260603-含PEG脂质体.dat` | 798 | 0.30 – 4.36 |

**分析方法**（参照 Schilt et al. 2016, BBA 的无限平膜模型 Eq. (1)）:

- 膜电子密度 Δρ(z) 用高斯叠加表示: 头基（±zh, FWHM τ_h）+ 疏水尾（中心, FWHM τ_t）；含PEG样品再加 PEG 层（±z_peg, FWHM τ_peg）
- 形状因子取 |Δρ̃(q)|² 的膜法向计算，取向平均后乘 2π³/q²
- 层间相关用结构因子 S(q) = 1 + f·exp(−q²sd²/2)·cos(qd)（Cauchy 型）
- 背景用常数 B 近似（背景很弱，扣除后仅个别参数数值有变化，定性结论不变）

**拟合策略**（论文协议）:

1. 先用 3-高斯膜模型拟合**不含PEG**样品（A 方案，放宽边界），得到膜结构参数
2. 固定膜参数（zh, τ_h, τ_t, drho_t），用 5-高斯膜模型拟合**含PEG**样品，提取 PEG 层参数
3. 附加诊断计算（F 检验、τ/z 扫描）检验参数稳健性

---

## 一、不含PEG脂质体（R0-26080301）

模型: 3-高斯膜 + S(q) + 常数背景（9 参数），**χ²/dof = 2.09**

### 1.1 拟合参数

| 参数 | 数值 | 物理含义 | 备注 |
|---|---|---|---|
| A | ~1×10⁻⁴ | 比例因子 | 显示精度受限 |
| zh | 1.6428 ± 0.2133 nm | 头基半距 | |
| τ_h | 1.3000 ± 0.2293 nm | 头基 FWHM | ⚠️ 撞上界 (1.30) |
| τ_t | 0.6566 ± 0.5825 nm | 尾链 FWHM | |
| drho_t/drho_h | −6.0000 ± 4.8741 | 尾/头电子密度对比 | ⚠️ 撞下界 (−6.00) |
| f | 0.2659 ± 0.0104 | 双层强度分数 | |
| d | 6.5119 ± 0.0151 nm | 层间距 | |
| sd | 0.6437 ± 0.0394 nm | 层间距涨落 | |
| B | 0.0054 ± 0.0003 | 常数背景 | |

### 1.2 导出量

| 量 | 数值 | 说明 |
|---|---|---|
| 头-头距离 d_hh = 2·zh | 3.29 ± 0.43 nm | 典型脂质双层范围 |
| 双层相关峰 q₁ = 2π/d | 0.965 nm⁻¹ | 低 q 隆起位置 |
| 头基 10% 外缘 | 2.83 nm | zh + 0.91·τ_h |

### 1.3 结论

1. **多层脂质体分散体系**: f = 0.27，存在清晰的层间相关峰（q₁ ≈ 0.97 nm⁻¹）
2. **膜结构基准**: d_hh ≈ 3.3 nm、d ≈ 6.5 nm、sd ≈ 0.64 nm，符合 PC 类脂质双层预期
3. **⚠️ 膜高斯参数的局限**: τ_h 与 drho_t 同时撞边界、误差大（drho_t ±4.87），说明 3-高斯膜模型未能完全表达数据中的某些成分（如尺寸多分散、膜内药物分布的漫散射等）。这组膜参数按论文协议作为**条件基准**固定用于含PEG样品拟合，其绝对值不宜单独引用
4. χ²/dof = 2.09 偏高，主要来自中高 q 段的系统偏差（模型较简单）

## 二、含PEG脂质体（20260603）

模型: 5-高斯膜（膜参数固定自 §1.1）+ S(q) + 常数背景（8 参数），**χ²/dof = 1.212**

### 2.1 拟合参数

| 参数 | 数值 | 物理含义 | 备注 |
|---|---|---|---|
| A | ~1×10⁻⁴ | 比例因子 | 显示精度受限 |
| f | 0.3353 ± 0.0102 | 双层强度分数 | |
| d | 9.0502 ± 0.0402 nm | 层间距 | |
| sd | 1.8195 ± 0.0454 nm | 层间距涨落 | |
| B | 0.0061 | 常数背景 | |
| z_peg | 4.4962 ± 0.0612 nm | PEG 高斯中心 | ≈ d/2 = 4.53 |
| τ_peg | 0.8000 ± 0.3396 nm | PEG 高斯 FWHM | ⚠️ 撞下界 (0.80) |
| drho_peg/drho_h | 0.0494 ± 0.0180 | PEG/头基电子密度对比 | |

### 2.2 模型比较与检出显著性

| 模型 | 参数数 | χ²/dof | χ² |
|---|---|---|---|
| 无PEG（同一数据重拟合） | 5 | 1.606 | 1273.3 |
| 含PEG | 8 | 1.212 | 943.9 |

- Δχ² = 329，嵌套 F 检验 F(3, 790) = 92 → p ≪ 10⁻³⁰，**PEG 项检出压倒性显著**
- PEG 层对曲线的最大相对影响约 3.9%——log 坐标下肉眼不可辨，但统计上极强
- 边际显著性 "2.7σ" 是 τ 锁在 0.80 边界时的条件值；τ 放宽后 drho_peg 与 τ_peg 完全反相关（corr ≈ −1.00），数据实际约束的是"位置 × 积分电子对比度"

### 2.3 PEG 层几何参数

| 量 | 数值 | 说明 |
|---|---|---|
| 头基 10% 外缘 | 2.83 nm | 固定 |
| PEG 10% 外缘 | 5.23 nm | z_peg + 0.91·τ_peg |
| PEG 层厚度 L_peg | 2.40 ± 0.32 nm | τ = 0.8 条件值 |
| L_peg 稳健范围 | **2.0 – 2.8 nm** | τ ∈ [0.3, 1.3] 扫描 |
| Flory 半径 R_F | ~3.5 nm | PEG2000 |
| L_peg / R_F | **0.69**（稳健范围 0.56 – 0.80） | 构象判据 |
| 双层相关峰 q₁ = 2π/d | 0.694 nm⁻¹ | |
| 水隙宽度 | 3.39 nm | d − 2×2.83 |
| PEG 中心位置 | z_peg = 4.50 ≈ d/2 | 水隙中央 |

### 2.4 结论

1. **PEG 层存在，统计上压倒性显著**（F = 92）。位置检验（固定 z 扫描）: 额外密度只在层间水隙中部（z ≈ 4.5 nm）显著改善拟合，放在头基附近（z = 2.5 – 3.0）完全不改善 → 是真实的水隙内密度（PEG 冠层），不是膜模型误差补偿

   | z_peg (nm) | 2.5 | 3.0 | 3.5 | 4.0 | **4.5** | 5.0 |
   |---|---|---|---|---|---|---|
   | χ²/dof | 1.61 | 1.55 | 1.38 | 1.31 | **1.19** | 1.33 |

2. **PEG 构象为蘑菇/过渡区**: L_peg/R_F = 0.69 < 1。刷状区需要 τ ≳ 2.2（L/R_F ≥ 1），对应 Δχ² ≈ 70 – 110，被强烈排除；即使按较宽蘑菇链段尺度（τ ≈ 1.3 – 1.6）固定，L/R_F = 0.80 – 0.87 仍在蘑菇一侧。**结论对 τ 简并不敏感，与 Zeta 电位结果互相印证**

   | τ_peg (nm) | 0.3 | **0.8** | 1.3 | 2.0 | 3.0 |
   |---|---|---|---|---|---|
   | χ²/dof | 1.193 | **1.210** | 1.239 | 1.284 | 1.334 |
   | L_peg (nm) | 1.97 | **2.40** | 2.80 | 3.33 | 4.06 |

3. **PEG 位置图像**: z_peg ≈ d/2，即水隙中央（水隙宽 3.4 nm < 2R_F = 7.0 nm）——两侧蘑菇冠层强烈交叠、链段密度在水隙中央叠峰，物理自洽
4. **拟合质量**: χ²/dof = 1.21，q < 3 nm⁻¹ 残差在 ±10% 内随机分布

## 三、跨样品对比（PEG 化的直接证据）

| 参数 | 不含PEG | 含PEG | 变化 | 解读 |
|---|---|---|---|---|
| d 层间距 | 6.51 ± 0.02 nm | 9.05 ± 0.04 nm | **+39%** | PEG 位阻使水层变厚 |
| sd 层间涨落 | 0.64 ± 0.04 nm | 1.82 ± 0.05 nm | **×2.8** | PEG 涂层打乱层间堆垛 |
| f 双层强度分数 | 0.266 | 0.335 | +26% | 层间相关略增强 |

d 与 sd 在两个样品中均拟合得非常确定、且**不依赖 PEG 参数化方式**，是模型无关性最强的证据；d 增大 + sd 增大是教科书式 PEG 化效应，与水隙中央检出额外电子密度互相印证。

---

## 四、总体结论

1. 两个样品均为**多层脂质体**分散体系（存在层间相关峰）
2. 不含PEG样品提供了膜结构基准（d_hh ≈ 3.3 nm、d ≈ 6.5 nm、sd ≈ 0.64 nm）；膜高斯参数存在边界约束问题，作为条件基准使用
3. 含PEG样品**检出 PEG 冠层**，压倒性显著:
   - PEG 中心位于层间水隙中央（z ≈ d/2 ≈ 4.5 nm）
   - L_peg ≈ 2.4 nm（稳健范围 2.0 – 2.8 nm），L_peg/R_F ≈ 0.69
   - **蘑菇/过渡区构象，与 Zeta 电位结果相符**
   - PEG 化使层间距 +39%、层间涨落 ×2.8——PEG 空间位阻的直接体现
4. 以上定性结论不依赖背景扣除（背景很弱，扣除后仅个别参数数值变化）

---

## 五、注意事项

1. **参数显示**: A、B 的 "±0.0000" 是 `%.4f` 格式截断，建议改 `%.2e`
2. **τ_peg 撞界**: 数据偏好比 0.80 更窄的 PEG 高斯；引用 L_peg 时建议给出 τ 简并范围 2.0 – 2.8 nm
3. **显著性表述**: 建议报 F 检验（Δχ² = 329, F = 92）而非 "2.7σ"——后者既低估检出显著性，又掩盖参数分解的脆弱性
4. **膜参数固定的局限**: 固定膜参数来自撞边界的不含PEG拟合，PEG 参数是其条件解；如需进一步验证可做膜参数全自由的 12 参数拟合（注意过参数化风险）
