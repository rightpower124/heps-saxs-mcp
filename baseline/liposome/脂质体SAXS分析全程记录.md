## 3. 参考文献中和我们数据分析相关的内容

### 3.1 文献信息

- **标题**：*Using solution X-ray scattering to determine the high-resolution structure and morphology of PEGylated liposomal doxorubicin nanodrugs*
- **作者**：Y. Schilt, T. Berman, X. Wei, Y. Barenholz, U. Raviv（希伯来大学，以色列）
- **期刊**：Biochimica et Biophysica Acta (BBA), 2016；DOI: 10.1016/j.bbagen.2015.09.012
- **研究对象**：PEG 化阿霉素脂质体（PLD，Doxil® 及其仿制药、LC100）远程载药前后的高分辨结构；硫酸铵/甲磺酸铵梯度载药；与同配方无药脂质体对照
- **方法**：液相 SAXS/WAXS + 高分辨分析工具，测定膜电子密度剖面、PEG 层厚度与密度、脂质体内药物结构

### 3.2 核心分析模型

**（1）无限平膜模型（论文 Eq. (1)）**

膜的电子密度剖面用高斯叠加表示（τ 均为 FWHM 参数化）：

- 3-高斯膜：头基 ±zh（宽 τ_h）+ 疏水尾链（中心，宽 τ_t，相对幅度 Δρ_t）
- 5-高斯膜（PEG 样品）：再加对称 PEG 层 ±z_peg（宽 τ_peg，幅度 Δρ_peg）

单个高斯分量：Δρᵢ · exp[−4ln2 · (z − zᵢ)² / τᵢ²]

随机取向平膜的形状因子（高斯对干涉双重求和）：

```
I_mem(q) = (2π³/q²) · Σᵢ Σⱼ [ Δρᵢ·Δρⱼ·τᵢ·τⱼ / (16·ln2) ]
           · exp[ −q²·(τᵢ² + τⱼ²) / (16·ln2) ] · cos[ q·(zᵢ − zⱼ) ]
```

**（2）层间相关（多层堆垛，Z = 2 结构因子简化式）**

```
S(q) = 1 + f · exp(−q²·sd²/2) · cos(q·d)
```

d = 层间距；sd = 层间距涨落（高斯阻尼宽度）；f = 相关堆垛双层的散射强度分数。

**（3）总模型**

```
I(q) = A · I_mem(q) · S(q) + B
```

## 4. 两个拟合脚本

### 4.1 fit_nopeg_membrane.py —— 不含 PEG 样品

**任务**：拟合膜结构基准（9 参数）。
**模型**：`I(q) = A·I₃ᴳ(q; zh, τ_h, τ_t, Δρ_t)·[1 + f·e^(−q²sd²/2)·cos(qd)] + B`

核心代码（模型数学核心）：

```python
def drho_profile(z, zh, tau_h, tau_t, drho_t):
    return (np.exp(-4*LN2*(z + zh)**2 / tau_h**2)
            + np.exp(-4*LN2*(z - zh)**2 / tau_h**2)
            + drho_t * np.exp(-4*LN2 * z**2 / tau_t**2))

def I_membrane(qq, zh, tau_h, tau_t, drho_t):
    z   = np.array([-zh, 0.0, zh])
    tau = np.array([tau_h, tau_t, tau_h])
    dr  = np.array([1.0, drho_t, 1.0])
    out = np.zeros_like(qq)
    for i in range(3):
        for j in range(3):
            out += (dr[i]*dr[j]*tau[i]*tau[j] / (16*LN2)
                    * np.exp(-qq**2*(tau[i]**2 + tau[j]**2)/(16*LN2))
                    * np.cos(qq*(z[i] - z[j])))
    return 2*np.pi**3 / qq**2 * out

def model(p, qq):
    A, zh, tau_h, tau_t, drho_t, f, d, sd, B = p
    Sq = 1.0 + f*np.exp(-qq**2*sd**2/2.0)*np.cos(qq*d)
    return A*I_membrane(qq, zh, tau_h, tau_t, drho_t)*Sq + B
```

参数、初值与边界（A 方案）：

| # | 参数 | 初值 | 下界 | 上界 | 拟合结果 ± 误差 |
|---|---|---|---|---|---|
| 1 | A 比例因子 | 中低 q 归一估计 | 0 | ∞ | ≈1×10⁻⁴ |
| 2 | zh 头基半距 (nm) | 1.45 | 0.90 | 2.20 | 1.6428 ± 0.2133 |
| 3 | τ_h 头基 FWHM (nm) | 0.50 | 0.25 | 1.30 | 1.3000 ± 0.2293 ⚠ 撞上界 |
| 4 | τ_t 尾链 FWHM (nm) | 1.00 | 0.50 | 1.80 | 0.6566 ± 0.5825 |
| 5 | Δρ_t/Δρ_h | −1.00 | −6.00 | −0.10 | −6.0000 ± 4.8741 ⚠ 撞下界 |
| 6 | f 双层强度分数 | 0.60 | 0 | 1 | 0.2659 ± 0.0104 |
| 7 | d 层间距 (nm) | 8.50 | 5.50 | 16.0 | 6.5119 ± 0.0151 |

### 4.2 fit_peg_membrane.py —— 含 PEG 样品

**任务**：固定膜参数，检出并表征 PEG 层（8 参数 + 无 PEG 对照拟合）。
**策略**：膜参数固定自 4.1 的结果（ZH=1.6428, TAU_H=1.3000, TAU_T=0.6566, DRHO_T=−6.0000），只拟合全局量（A, f, d, sd, B）+ PEG 三参数（z_peg, τ_peg, Δρ_peg）。

**模型**：`I(q) = A·I₅ᴳ(q; z_peg, τ_peg, Δρ_peg)·[1 + f·e^(−q²sd²/2)·cos(qd)] + B`

核心代码（5-高斯膜 = 固定 3-高斯膜 + 对称 PEG 层）：

```python
def I_membrane5(qq, z_peg, tau_peg, drho_peg):
    z   = np.array([-z_peg, -ZH, 0.0, ZH, z_peg])        # ZH等为大写常量=固定膜参数
    tau = np.array([tau_peg, TAU_H, TAU_T, TAU_H, tau_peg])
    dr  = np.array([drho_peg, 1.0, DRHO_T, 1.0, drho_peg])
    out = np.zeros_like(qq)
    for i in range(5):
        for j in range(5):
            out += (dr[i]*dr[j]*tau[i]*tau[j]/(16*LN2)
                    * np.exp(-qq**2*(tau[i]**2 + tau[j]**2)/(16*LN2))
                    * np.cos(qq*(z[i] - z[j])))
    return 2*np.pi**3 / qq**2 * out
```

PEG 层厚度（10% 判据，与论文一致）：

```python
c10 = np.sqrt(np.log(10)/(4*LN2))      # = 0.911（高斯降到峰值10%处的半宽）
edge_head = ZH + c10*TAU_H             # 头基 10% 外缘 = 2.83 nm
edge_peg  = z_peg + c10*tau_peg       # PEG 10% 外缘 = 5.23 nm
L_peg = edge_peg - edge_head           # = 2.40 nm
```

## 5. 两个拟合得到的参数该如何解释

### 5.1 不含 PEG 样品（9 参数，χ²/dof = 2.09）

| 参数 | 数值 | 物理意义与解释 |
|---|---|---|
| A | ≈1×10⁻⁴ | 比例因子：电子密度对比 × 浓度 × 仪器常数的总归一 |
| zh | 1.6428 ± 0.2133 nm | 头基半距：双层中心到头基密度峰的距离 → 膜厚度核心参数 |
| τ_h | 1.3000 ± 0.2293 nm | 头基高斯 FWHM：头基区表观宽度 ⚠ 撞上界，绝对值偏大慎引 |
| τ_t | 0.6566 ± 0.5825 nm | 尾链高斯 FWHM：甲基低谷宽度；误差大（与 Δρ_t 强简并） |
| Δρ_t/Δρ_h | −6.0000 ± 4.8741 | 尾链/头基电子密度对比（负 = 尾链电子密度低于水）⚠ 撞下界 |
| f | 0.2659 ± 0.0104 | 相关堆垛双层的散射分数：约 27% 散射权重来自多层（MLV），其余为非相关单层（ULV） |
| d | 6.5119 ± 0.0151 nm | 层间距：相邻双层中心的重复距离 |
| sd | 0.6437 ± 0.0394 nm | 层间距涨落：多层堆垛的失序程度（相关峰的高斯阻尼宽度） |
| B | 0.0054 ± 0.0003 | 常数背景（水 + 毛细管 + 漫散射的合并近似） |

**导出量**：

| 量 | 公式 | 数值 |
|---|---|---|
| 头-头距离 d_hh | 2·zh | 3.29 ± 0.43 nm（**膜厚度 ★**） |
| 头基 10% 外缘 | zh + 0.91·τ_h | 2.83 nm |
| 全膜厚（10% 判据） | 2·(zh + 0.91·τ_h) | 5.65 nm |
| 层间水层 | d − 全膜厚 | 0.86 nm |
| 一级相关峰位 q₁ | 2π/d | 0.965 nm⁻¹ |
| 疏水核心（粗估） | 2·zh − τ_h | ≈2.0 nm |
| 头-尾 FWHM 间隙 g | zh − (τ_h + τ_t)/2 | 0.66 nm |

**解释要点**：

1. **多层脂质体分散体系**：f = 0.27 且低 q 有清晰层间相关峰（q₁ ≈ 0.97 nm⁻¹）。
2. **膜结构基准**：d_hh ≈ 3.3 nm、d ≈ 6.5 nm、sd ≈ 0.64 nm，符合 PC 类脂质双层预期。
3. **⚠ 膜高斯参数的局限**：τ_h 与 Δρ_t 同时撞边界、误差大（Δρ_t ±4.87），说明 3-高斯模型未能完全表达数据中的某些成分（如尺寸多分散、膜内药物分布的漫散射等）。这组膜参数按论文协议作为**条件基准**固定用于含 PEG 样品拟合，其绝对值不宜单独引用。
4. χ²/dof = 2.09 偏高，主要来自中高 q 段的系统偏差（模型较简单），拟合曲线与数据在 log 坐标下视觉重合。

| B | 0.0061 | 常数背景 |
| z_peg | 4.4962 ± 0.0612 nm | PEG 高斯中心 ≈ d/2 = 4.53 → 位于层间水隙中央 |
| τ_peg | 0.8000 ± 0.3396 nm | PEG 云 FWHM ⚠ 撞下界；与 Δρ_peg 强反相关（corr ≈ −1） |
| Δρ_peg/Δρ_h | 0.0494 ± 0.0180 | PEG/头基电子密度对比（正 = PEG 区密度略高于水） |

**导出量**：

| 量 | 公式 | 数值 |
|---|---|---|
| 头基 10% 外缘 | 固定膜参数 | 2.83 nm |
| PEG 10% 外缘 | z_peg + 0.91·τ_peg | 5.23 nm |
| PEG 层厚度 L_peg | PEG 外缘 − 头基外缘 | 2.40 ± 0.32 nm（稳健范围 2.0 – 2.8） |
| Flory 半径 R_F | PEG2000 | ≈3.5 nm |
| 构象判据 | L_peg/R_F | 0.69 → 蘑菇/过渡区构象 |
| 层间水隙宽 | d − 2×2.83 | 3.39 nm |
| 一级峰位 q₁ | 2π/d | 0.694 nm⁻¹ |

**检出显著性（诊断结论）**：

- F 检验：Δχ² = 329，F(3, 790) = 92 → p ≪ 10⁻³⁰，PEG 项压倒性显著。
- 位置扫描：额外密度只在 z ≈ 4.5（水隙中央）显著改善拟合；放在头基附近（z = 2.5 – 3.0）完全不改善 → 是真实的水隙内冠层密度，不是膜模型误差补偿。
- τ_peg 与 Δρ_peg 完全反相关：数据实际约束的是"位置 × 积分电子对比度"，L_peg 对 τ 简并不敏感（2.0 – 2.8 nm 全范围蘑菇构象）。
- "2.7σ" 边际显著性是 τ_peg 锁在边界时的条件值，建议引用 F 检验结果。
- PEG 层对曲线的最大相对影响仅 3.9%（log 坐标下肉眼不可辨，但统计上极强）。

### 5.3 参数可靠性分级

| 级别 | 参数 | 依据 |
|---|---|---|
| 稳健 | zh（→ d_hh）、d、sd、z_peg、L_peg（范围）、f | 误差小、多起点/多方案一致、对模型选择不敏感 |
| 条件值 | τ_h、Δρ_t、τ_peg、Δρ_peg | 撞边界或强简并，只宜配合范围引用 |
| 归一量 | A、B | 与浓度、背景扣除方式耦合，无独立结构含义 |

### 5.4 参数自洽性检验（全部通过）

| 检验项 | 关系 | 数值 | 结果 |
|---|---|---|---|
| 头-尾带间隙 | g = zh − (τ_h+τ_t)/2 | 0.66 nm > 0 | ✓ |
| 全膜厚 vs 层间距 | 2(zh+0.91τ_h) = 5.65 < d = 6.51 | 水层 0.86 nm | ✓ |
| d_hh 合理性 | 2·zh | 3.29 nm（典型 PC 双层 3 – 4 nm） | ✓ |
| PEG 构象 | L_peg/R_F | 0.69 ∈ (0.2, 1.4) 蘑菇区 | ✓ |
| PEG 位置 | z_peg vs d/2 | 4.50 ≈ 4.53；水隙 3.39 nm < 2R_F = 7.0 nm → 两侧蘑菇云交叠、链段密度在水隙中央叠峰 | ✓ |
| 相邻 PEG 云 | 2×5.23 − d | 10% 边界交叠 1.41 nm —— 软蘑菇链互穿，与 sd = 1.82 nm 涨落相容 | ✓ |

> 说明：zh、τ_h、τ_t 是三个相互独立的高斯参数（位置 / 头基宽度 / 尾链宽度），**不存在 zh = τ_h + τ_t 的几何约束**——该关系仅对"矩形板无缝拼接"成立，而高斯模型是平滑叠加。正确的相邻性检验是半高宽间隙 g > 0（头基带内缘与尾链带外缘之间留有空隙，高斯尾部在此平滑交叠）。

### 5.5 用户关心的"膜厚度"对应参数

- **d_hh = 2·zh = 3.29 ± 0.43 nm**：头-头距离，文献标准膜厚度定义，本方案最稳健的膜厚度；
- 全膜厚 = 2(zh + 0.91τ_h) = 5.65 nm：10% 判据下含头基外沿的总厚（依赖撞界的 τ_h，绝对值偏大）；
- 疏水核心 ≈ 2zh − τ_h ≈ 2.0 nm（粗估）；
- 稳健性验证：在含 PEG 数据上放开膜参数重拟合（方案 1），d_hh = 3.322 ± 0.010 nm，与固定值 3.29 一致 → 膜厚度结论可靠。

### 6.3 跨样品对比（PEG 化的直接证据）

| 参数 | 不含 PEG | 含 PEG | 变化 | 解读 |
|---|---|---|---|---|
| d 层间距 | 6.51 ± 0.02 nm | 9.05 ± 0.04 nm | **+39%** | PEG 位阻把水层撑厚 |

### 6.4 总结论

1. 两个样品均为**部分多层脂质体分散体系**（存在层间相关峰）。
2. **膜厚度 d_hh ≈ 3.3 nm**（头-头距离，稳健）；全膜厚 5.65 nm（10% 判据，条件值）。
3. 含 PEG 样品**检出 PEG 冠层**，压倒性显著（F = 92，p ≪ 10⁻³⁰）：
   - PEG 中心位于层间水隙中央（z ≈ d/2 ≈ 4.5 nm）；
   - L_peg ≈ 2.4 nm（稳健范围 2.0 – 2.8 nm），L_peg/R_F ≈ 0.69 → **蘑菇/过渡区构象**，与 Zeta 电位结果相符；
   - PEG 化使层间距 +39%、层间涨落 ×2.8。
4. 以上定性结论不依赖背景扣除（背景很弱，扣除后仅个别参数数值变化）。
