# SAXS 数据分析提示词库（用户关键词 → 标准分析流）

> **用途**：实验站用户的快捷入口。用户上传数据 + 报出【关键词】+ 附带必要信息，Agent 即按库内预调试好的工具链执行，快速响应、语句标准化。
> **维护**：工具面或模型库变化时由开发端同步更新本库；Agent 发现关键词歧义或缺失场景，当日回报开发端补充。
> **关系**：本库是"用户说什么"；`saxs_workflow.md` 是"Agent 怎么做"（编排 SOP 与质量门），冲突时以 workflow 为准。

## 0. 使用规则（用户侧三条）

1. **指明数据**：给出文件的完整路径（或上传后告知路径）；
2. **报关键词**：从下表选一个【关键词】写入消息（例："【完整分析】 E:\data\saxs_001.txt，q_unit=nm^-1"）；
3. **配合确认**：Agent 会回一张"四要素确认卡"，缺什么补什么——**单位必须显式给出，Agent 不做猜测**；工作目录确认后所有产出落该文件夹的 `HEPS_SAXS_analysis\` 子目录（不写数据根）。

## 2. 当前支持的分析能力（截至 2026-09-30，工具面 17 个）

### 2.1 模型库（拟合/出图/报告适用）

| 模型 | 状态 | 模式 | 说明 |
|---|---|---|---|
| liposome_membrane | validated（过三道验证门） | nopeg / peg | 3/5-高斯对称平膜+双层结构因子简化式；双样品膜参数传递流程 |
| sphere / core_shell_sphere / cylinder / ellipsoid / hollow_cylinder / core_shell_cylinder | external（sasmodels 1.1.0 桥接；2026-10-21 扩容 +2） | main | 官方基础形状，几何参数原生 Å；报告无模型专属结论。hollow_cylinder：radius=内腔半径、thickness=壁厚、scale=管壁体积分数 |

### 2.2 曲线整备（M3pre-2，1D 曲线 gap 剔除与填充）

- 适用：传感器模块间隙 / beamstop 支撑杆阴影导致的 gap 区域；横轴双语义 **I-q（A^-1/nm^-1/pixel，pixel 为探测器半径轴 2026-09-29 扩展）**与 I-phi（deg）；2 列（x I）或 N+1 列（x I1..In）逐列独立处理；批量整备可追加 merge 步骤产出与源文件同形的 `<原名>_filled_book.dat` 总表（Origin：原始 book 与填充 book 并排拖入，行/列一致、差异仅在 gap 单元）；
- 形态学四级：深谷核心（全自动）/ 孤立异常点（全自动）/ 渐变肩部（Agent 目检主判）/ 宽缓阴影（低置信提请用户裁决）；
- 交付 5 件套：`_filled.dat`（x 照抄+填充后 y，带表头信息块）/ `_mask.csv` / `_标记图.png` / `_整备报告.md` / `_result.json`；
- **填充值一律为条件值**：被遮挡处无光子记录，填充是数学插值而非信号恢复，填充占比写入下游使用披露。

### 2.3 取向分析（Ruland 独立工具链，第二个模型）

- 适用：2D SAXS 图经站内 pyFAI 链路积好的方位角积分曲线集 I(q_c, φ)（N+1 列文件，第 1 列 φ/deg）；峰形态学 2/4/8 峰一律只积最强峰，16 条曲线 series 级统一选同一位置附近的峰；
- 链路：gap 整备（盲区/深谷存在时）→ `saxs_ruland_bpi2`（触达式边界 f=0.02 主判 + 3σ 下限 + 3 点防抖；线性基线；高斯拟合峰高；高斯尾校正 ×1.005；B 表 + 逐列 QC 图）→ `saxs_ruland_beq`（x=q²、y=q²B² 线性区 OLS → B_eq；线性区窗口由用户裁决）；
- **截断积分口径**：只积到"剩余信号≈噪声地板"（与 Origin 默认峰积分模式同款的标准实践），截断损失由 erf 因子解析补回（f=0.02 漏损 ≲1%）——不要拖到水平基线（基线偏置 ∝ 窗宽，YR8 实测宽窗虚高 +14% 全为伪影）；
- **微孔长度 L 一律不产出**（L=2π/q 原则，模型法长度不可采信）；截距 <0 = 系统偏差信号触发线性区复核；
- 条件值披露：依赖填充单元的 B 列、q_span_narrow（q_c 跨度窄）、R²/LOO/曲率 flag——B_eq 结论按分级措辞。

### 2.4 标准触发语句示例

```text
【曲线整备】 E:\data\YR8_ruland.txt，x_semantic=phi，x_unit=deg，列 10
【曲线整备】 E:\data\1.dat，x_semantic=q，x_unit=pixel，列 1（R(pixel) 轴直读，无需换算）
【批量曲线整备】 E:\data\YR8_ruland.txt，phi/deg，全部 16 列，最后合并总表
【取向分析】 E:\data\YR8_..._filled_book.dat，phi/deg，q_unit=nm^-1（q_c 读文件头，确认后生效）
【完整分析】 E:\data\liposome_A.txt，q_unit=nm^-1，liposome_membrane 的 nopeg 模式
【拟合】 E:\data\np.txt，q_unit=A^-1，sphere，窗口 0.3–4.4 nm^-1
【放宽边界】 上轮 col10 拟合的 drho_t，边界放宽 2 倍看简并
```

## 3. Agent 标准化响应句式（快速响应模板）

### 3.1 四要素确认卡（分析前必回）

> 待确认四要素：① 数据路径 = `<路径>`？② 单位 = `<q_unit: A^-1/nm^-1 或 phi/deg>`？（显式确认，不猜测）③ 拟合窗口 = 窗口建议卡结果 `<qmin, qmax>`（初始=完整数据范围，按直通光/噪声证据建议扣除，**由你确认**）？④ 工作目录 = 数据所在文件夹 `<路径>`？（确认后所有产物落其下 `HEPS_SAXS_analysis\` 子目录）——确认后立即执行。

### 3.2 结果宣报顺序（固定）

1. **物理量结果 + 可靠性分级**（稳健 / 条件值 / 归一量）先行；
2. 再给技术细节（χ²、质量门、诊断建议）；
3. 撞界参数只作条件值呈现；模型显著性以 F 检验为准；χ²/dof > 3 先诊断后结论。

### 3.3 交付清单模板（固定）

> 交付物（runs\<案例>_<标签>\）：`<文件>_filled.dat` …（逐个列完整路径）。请 IDE 目检，runs 由你手动清空（我不执行删除）。

### 3.4 异常口径（固定）

- 工具报错 → 原样转述，不转译不美化；
- 回执与磁盘不符 → 明确声明"疑似显示层污染"，请用户 IDE 目检裁决；
- 超能力请求（2D/GISAXS、库外自定义模型）→ 如实告知边界，引导走开发端模型入库流程（workflow §7），不现场编造模型。

## 4. 能力边界

- **支持**：1D SAXS 数据的读取体检 / gap 曲线整备 / 模型拟合（5 模型）/ 四项参数诊断 / F 检验 / 标准图与报告闭环 / Ruland 取向分析（B_π/2 表与 B_eq）；
- **不支持**：2D SAXS、GISAXS、模型库外的自定义物理模型（→ workflow §7 入库流程提交开发端）。
